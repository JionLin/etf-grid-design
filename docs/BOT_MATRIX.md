## 1. 角色定义与分工

### 🛠️ Bot 1: 数据源与后端量化基石 (`etf-quant-engine`)
- **核心定位**：守护数据底层与数学逻辑，杜绝任何假数据或虚假回测。
- **核心管辖**：
  - MySQL 数据库（`etf_daily_bar` 453,540 条真实日 K 线）；
  - 14 日 Welles Wilder ATR 动态计算引擎；
  - A 股 T+1 状态机、100 股向下取整、万 1 最低 0.2 元真实佣金摩擦；
  - 看守后端 **151 个单元测试**，改动必须 100% 跑绿。
- **常用唤醒指令**：
  > “检查某标的（如 512480）的底层 K 线数据，核实它的 14 日 Wilder ATR 计算与回测收益是否准确。”
  > “运行全量 pytest 单元测试，检查是否有算法回归 Bug。”

---

### 🎨 Bot 2: 全栈功能与页面验收员 (`etf-fullstack-ui`)
- **核心定位**：守护浏览器端视觉呈现与用户交互体验，杜绝前后端断层。
- **核心管辖**：
  - 前端 React 18 / Tailwind CSS 组件与状态渲染；
  - 严查数据展示 Bug（百分比漏乘 100、浮点数精度溢出、字段名取错）；
  - 验证 0% ~ -60% 跌幅滑块、三色彩虹分轨利润图、20 档买卖价位表；
  - 具备全栈穿透修复能力，修复后自动执行 `npm run build` 确保 0 报错。
- **常用唤醒指令**：
  > “检查首页科技芯片卡片上的 ATR 百分比和价格是否与后端返回的数据完全一致。”
  > “修复分析页面滑块拖动时的数值显示 Bug，并确保前端构建正常。”

---

### 📈 Bot 3: 实盘策略推演与操盘顾问 (`etf-strategy-advisor`)
- **核心定位**：站在真实交易员角度，用已验真的数据带你做 ETF 网格实操。
- **核心管辖**：
  - 开网前 4 维量化体检（波动率 15%~45%、Wilder ADX < 20 震荡判据、日均成交额 > 3000 万）；
  - 50:50 底仓与小(20%)/中(35%)/大(45%)三轨资金配比；
  - 0% ~ -60% 极限抗跌沙盘推演（测算水淹线与绝地脱困标尺）；
  - 输出可直接录入同花顺、华宝智投、银河玖乐 APP 的 20 档条件单；
  - 捍卫 E 大 2.0/3.0 哲学底线（严禁估值抄底、严格执行小网 5 格熔断）。
- **常用唤醒指令**：
  > “我现在有 10 万元资金，想做芯片 ETF（512760），帮我做个完整的 4 维体检与 -60% 暴跌抗跌方案，并输出券商条件单。”

## 2. 如何启动与切换

### 方式 1：Hermes Desktop 桌面客户端
在 Hermes Desktop 左上角或 Profile 下拉菜单中，直接点击切换：
- `etf-quant-engine`
- `etf-fullstack-ui`
- `etf-strategy-advisor`

### 方式 2：终端 CLI 命令
```bash
# 启动数据与算法质检 Bot
hermes --profile etf-quant-engine

# 启动全栈与页面验收 Bot
hermes --profile etf-fullstack-ui

# 启动实盘策略推演 Bot
hermes --profile etf-strategy-advisor
```
