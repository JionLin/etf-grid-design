## 🏗️ 系统技术架构

### 后端架构
- **核心框架**：Python 3.10+ / Flask 3.0+
- **数据引擎**：Tencent Finance API (极速降级) + AkShare / TuShare
- **算法模块**：
  - `CompositeGridCalculator`：大中小三层复合网格资金拆解与多轨阶梯合并排序
  - `GridBacktestEngine`：A 股 T+1 隔夜持仓簿记与模式 B 利润蓄水池状态机
  - `GridOptimizer`：基于 Welles Wilder 14日半周期 ATR 步长优化

### 前端架构
- **开发与构建**：React 18 + Vite 5
- **样式与组件**：Tailwind CSS 3.4 + Lucide React 图标体系
- **推演引擎**：纯函数式客户端毫秒级沙盘演算（`< 16ms`，60fps 拖拽无感延迟）
- **图表系统**：原生轻量 SVG 矢量图表，零第三方笨重图表依赖

## 🚀 极速上手开发指南

### 环境要求
- Python 3.10+ (推荐使用 [uv](https://github.com/astral-sh/uv) 包管理器)
- Node.js 18+ 与 npm

### 本地一键启动

```bash
# 1. 克隆代码仓库
git clone https://github.com/jorben/etf-grid-design.git
cd etf-grid-design

# 2. 安装 Python 依赖并启动后端服务（端口 5001）
uv sync
uv run python backend/app.py

# 3. 在新终端安装前端依赖并启动开发服务器（端口 3000）
cd frontend
npm install
npm run dev
```

启动完成后，打开浏览器访问：
👉 **http://localhost:3000**

## 📖 核心模块使用指引

1. **挑选标的**：在首页选择或输入代码（如 `515220` 煤炭 ETF、`512890` 红利低波 ETF）；
2. **设定资金与周期**：勾选资金预设（如 3 万元、5 万元）并选择历史分析周期（推荐 180 天黄金平衡）；
3. **配置 E大 2.0 进阶机制**：
   - **做 T 收益模式**：默认推荐【★ 智能利润滚存留股】（攒满 100 股自动沉淀为 0 成本份额）；
   - **逢跌买入节奏**：可开启【📐 逐格加码】，选择 10%（E大推荐）；
4. **查阅立体阶梯**：点击“开始分析策略”，在【立体网格策略】页面查看 20 档多轨合并挂单，支持一键复制到证券交易 APP；
5. **沙盘推演**：在阶梯表下方拖动跌幅滑块，实时观察各轨水淹击穿状态与绝地脱困反弹阈值；
6. **历史回测验证**：切换至【历史策略回测】标签页，查阅 0 成本免费份额沉淀库、超额收益 Alpha 曲线与三轨彩虹利润归因。
