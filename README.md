## 🏗️ 系统技术架构

### 后端架构
- **核心框架**：Python 3.10+ / Flask 3.0+
- **数据引擎**：Tencent Finance API (极速降级) + AkShare / TuShare
- **算法模块**：
  - `CompositeGridCalculator`：大中小三层复合网格资金拆解、万1最低0.2元保底手续费与多轨阶梯合并排序
  - `GridBacktestEngine`：A 股 T+1 隔夜持仓簿记、实盘级逐笔摩擦扣费与模式 B 利润蓄水池状态机
  - `GridOptimizer`：基于 Welles Wilder 14日半周期 ATR 步长优化及 E大原版 5%/15%/30% 双模式生成

### 前端架构
- **开发与构建**：React 18 + Vite 5
- **样式与组件**：Tailwind CSS 3.4 + Lucide React 图标体系
- **路由与参数**：React Router 6 + 全量参数 URL 双向序列化同步引擎（`url.js`）
- **推演引擎**：纯函数式客户端毫秒级沙盘演算（`< 16ms`，60fps 拖拽无感延迟）
- **状态监控**：网格运行三态边界哨兵与超深水淹满仓解释组件
- **图表系统**：原生轻量 SVG 矢量图表，零第三方笨重图表依赖

## 🚀 极速上手开发指南

### 环境要求
- Python 3.10+ (推荐使用 [uv](https://github.com/astral-sh/uv) 包管理器)
- Node.js 18+ 与 npm

### 本地一键启动

```bash
# 1. 克隆代码仓库
git clone https://github.com/jorben/etf-grid-design.git
cd etf-grid-design

# 2. 安装 Python 依赖并启动后端服务（端口 5001）
uv sync
uv run python backend/app.py

# 3. 在新终端安装前端依赖并启动开发服务器（端口 3000）
cd frontend
npm install
npm run dev
```

启动完成后，打开浏览器访问：
👉 **http://localhost:3000**

## 📖 核心模块使用指引

1. **挑选标的**：在首页选择或输入代码（如 `515220` 煤炭 ETF、`512890` 红利低波 ETF）；
2. **基准价格设置（P₀ 锚点）**：
   - **⚡ 最新收盘市价（默认）**：自动跟随当前市场价格；
   - **✏️ 自定义成本/心理价**：手动输入自己的持仓成本均价（如 1.250 元），买卖阶梯将围绕该锚点铺设；
3. **设定资金与周期**：勾选资金预设（如 3 万元、5 万元、10 万元）并选择历史分析周期（推荐 180 天黄金平衡）；
4. **选择步长生成模式**：
   - **★ 🌊 ATR 动态自适应（默认）**：高频做 T，日常现金流充沛；
   - **🏛️ E大原版经典大步长**：小网 5% / 中网 15% / 大网 30%，适合跨周期大波段守株待兔；
5. **配置 E大 2.0 进阶机制**：
   - **做 T 收益模式**：默认推荐【★ 智能利润滚存留股】（攒满 100 股自动沉淀为 0 成本份额）；
   - **逢跌买入节奏**：可开启【📐 逐格加码】，选择 10%（E大推荐）；
6. **查阅立体阶梯与状态机哨兵**：点击“开始分析策略”，在【立体网格策略】页面：
   - 顶部实时查看【网格运行状态哨兵】（正常巡航 / 向上超轨休眠 / 底部沉底待机）；
   - 查看 20 档多轨合并挂单，支持一键复制到证券交易 APP；
7. **沙盘推演**：在阶梯表下方拖动跌幅滑块，实时观察各轨水淹击穿状态与绝地脱困反弹阈值（跌幅超限时自动呈现【超深水淹满仓状态】解释横幅）；
8. **历史回测验证**：切换至【历史策略回测】标签页，查阅在万 1 最低 0.2 元实盘费率下的 0 成本免费份额沉淀库、超额收益 Alpha 曲线与三轨彩虹利润归因；
9. **一键分享复现**：点击页面右上角“分享报告”，复制带有全量参数（包含自定义基准价）的专属 URL，他人打开即可 100% 完整复现您的策略配置。
